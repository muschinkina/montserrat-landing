Montserrat
Это лендинг про шрифт для арт-практики. 

Всё сделано с помощью HTML и CSS.

**Как открыть**
Скачать репозиторий и открыть index.html в браузере. Шрифт подгружается с Google Fonts, так что нужен интернет.

**Что внутри**
index.html — разметка
style.css — стили
img/ — картинки
